# Security Policy

## Supported versions

Security fixes are applied to the latest published WatchTower release.

## Reporting a vulnerability

Please do not publish credentials, webhook URLs, tokens, passwords, or sensitive reproduction data in a public issue.

For non-sensitive security hardening suggestions, open a GitHub issue with a minimal reproduction and the affected version. For a vulnerability that would expose user secrets or enable unintended access, use GitHub's private vulnerability reporting feature if it is enabled for the repository.

## Scope

WatchTower is intended to monitor public web content. Reports involving bypassing authentication, CAPTCHAs, access controls, rate limits, or anti-bot systems are outside the intended product scope.
